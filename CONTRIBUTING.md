# Contributing

Bug reports and focused pull requests are welcome. Before submitting a change:

1. Do not include copyrighted music, personal library databases, or USB-drive backups.
2. Add or update tests for format or conversion changes.
3. Run the `CueMirror` test scheme in Xcode.
4. Clearly describe the audio format and hardware/firmware used for any compatibility result.

Please test write-path changes on a backed-up USB drive. Do not report a device as supported based only on successful file generation.
